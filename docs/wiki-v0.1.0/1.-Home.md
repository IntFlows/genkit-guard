# Genkit Guard — v0.1.0

[Try the Hugging Face Space](https://huggingface.co/spaces/intflows/genkit-guard). Use synthetic inputs when exploring the hosted demo.

Validate intent and mask personal information before a Genkit model call. Restore masking tokens in responses and tool inputs.

This release adds a typed, reusable `guard.config.ts`, consistent intent model selection during startup and requests, and custom PII label mappings.

Start with [[3.-Getting-Started]], then see [[8.-Shared-Model-Configuration]]. Existing inline configuration continues to work.

Release 1 tool policies and the versioned decision log contract are described in [[9.-Tool-Controls-and-Logging]].

New in v0.1.0: [[10.-Decision-Storage-and-Model-Fallback|Persistent decision storage and fallback guard models]]. Existing model defaults and inline configuration remain supported.
