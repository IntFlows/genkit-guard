# Intent guard

The guard checks known injection phrases, then embeds each intent description and the input, computes cosine similarity, and compares the highest score with `intent.semantic.threshold` (default `0.7`).

```ts
models: { extractor: "Xenova/all-MiniLM-L6-v2" },
intent: {
  mode: "semantic",
  allowedIntent: "integration",
  semantic: {
    threshold: 0.7,
    intents: { integration: "Azure Blob Storage, APIs and integration workflows" }
  }
}
```

In v0.1.0, `models.extractor` controls both preloading and runtime analysis. Previously runtime analysis always used MiniLM. Custom models must support the Transformers.js feature-extraction pipeline with mean pooling and normalized embeddings.

All entries in `semantic.intents` participate in scoring. `allowedIntent` and `mode` remain accepted for compatibility; they do not select a separate enforcement path. List only the intent descriptions you want to allow. Tune thresholds against representative allowed and disallowed prompts.
