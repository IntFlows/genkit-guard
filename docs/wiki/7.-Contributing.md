# Contributing

Contributions to guard behavior, PII coverage, performance and documentation are welcome.

Run `npm ci` and `npm test`. The suite covers type checking and builds, masking/storage/concurrency, real Genkit orchestration with mock inference, and release regressions. Run `npm run test:release3` for security and operational-error regressions. Real Redis checks run separately with `npm run test:redis`.

The compatibility workflow tests minimum supported and latest stable Genkit on Node.js 22 and 24. Local passing tests do not establish that remote CI passed. See [[11.-Framework-Compatibility]].

Keep documentation in `docs/wiki`. Update numbered pages in place; do not create release-specific wiki folders. From the repository root, `npm run wiki:publish` previews the remote diff; adding `-- --publish` commits and pushes it. Authentication and wiki write access are required.

The next release, **v1.0.0-rc.1**, establishes the public API freeze. Preserve exports, configuration, decision schema and error codes after that milestone; API changes require explicit review before stable v1.
