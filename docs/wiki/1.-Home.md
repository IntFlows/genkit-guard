# Genkit Guard

[Try the Hugging Face Space](https://huggingface.co/spaces/intflows/genkit-guard) with synthetic inputs.

Genkit Guard checks injection patterns and semantic intent, masks detected personal data before model calls, restores tokens in responses and tool inputs, and enforces tool policies. Detection can miss attacks or PII and reject valid requests; keep authorization in your application.

These pages describe v1.0.0-rc.1, prepared locally and unpublished. Open release gates are recorded in docs/rc.1-readiness.md. Documentation is maintained in a single docs/wiki folder.
