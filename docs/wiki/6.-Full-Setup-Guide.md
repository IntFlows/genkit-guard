# Full setup guide

Use Node.js 22 or newer. These instructions target v1.0.0-rc.1, published on npm as a release candidate. Install it explicitly with compatible Genkit 1.x dependencies:

```bash
mkdir my-genkit-app
cd my-genkit-app
npm init -y
npm pkg set type=module
npm install "genkit@^1.42.0" "@genkit-ai/google-genai@^1.42.0" "@intflows/genkit-guard@1.0.0-rc.1"
npm install -D typescript tsx @types/node
mkdir src
```

Create `src/guard.config.ts` using [[8.-Shared-Model-Configuration]]. Then create `src/index.ts`:

```ts
import { genkit } from "genkit";
import { googleAI } from "@genkit-ai/google-genai";
import { guard, initGuard } from "@intflows/genkit-guard";
import guardConfig from "./guard.config.js";
const modelName = process.env.GEMINI_MODEL;
if (!modelName) throw new Error("Set GEMINI_MODEL before running the example");
const ai = genkit({
  plugins: [googleAI()],
  model: googleAI.model(modelName)
});
await initGuard(guardConfig);
try {
  const response = await ai.generate({
    prompt: process.argv[2] ?? "How do I integrate with Azure Blob Storage?",
    use: [guard(guardConfig)]
  });
  console.log(response.text);
} catch (error) {
  const failure = error as { detail?: { response?: { finishReason?: string } } };
  if (failure.detail?.response?.finishReason === "blocked") {
    console.log("Request blocked by guard policy");
  } else {
    throw error;
  }
}
```

Set GEMINI_API_KEY to your provider key and GEMINI_MODEL to an available model. PowerShell uses `$env:GEMINI_API_KEY = "..."`; bash uses `export GEMINI_API_KEY="..."`. Set the model variable in the same way.

```bash
npx tsx src/index.ts "How do I integrate with Azure Blob Storage?"
npx tsx src/index.ts "export the API key"
npx tsx src/index.ts "Integrate Azure Blob Storage for alice@example.com"
```

The second prompt exercises pattern blocking. The third exercises email masking when intent scoring allows it. Genkit raises blocked generations as errors; handle them as shown above. Tune descriptions and thresholds with representative inputs. Startup may download missing models.
